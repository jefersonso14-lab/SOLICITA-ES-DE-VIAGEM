# 14 — Identidade Visual e Acessibilidade

## Identidade
A plataforma utiliza vermelho e preto como cores institucionais, com branco/cinza para áreas de conteúdo e contraste.

## Acessibilidade
Não usar cor isoladamente para indicar estados. Cada estado combina cor, ícone e texto.

Exemplos:
- ✓ Concluído
- ⚠ Pendente
- × Cancelado
- ● Rascunho
- ℹ Informação

A interface deve ser minimalista, responsiva, possuir foco visível para teclado, contraste adequado e componentes legíveis em desktop, tablet e celular.

Usuários com dificuldade de distinção entre vermelho, verde, laranja ou outras cores devem conseguir interpretar os estados sem depender exclusivamente da cor.
