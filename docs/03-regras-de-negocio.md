# 03 — Regras de Negócio

1. Cada solicitação possui um solicitante responsável.
2. O solicitante consulta suas próprias OS e custos.
3. O solicitante não altera valores financeiros.
4. Gestor/Administrador possui permissões ampliadas.
5. Colaboradores são reutilizáveis e preferencialmente inativados, não apagados.
6. Veículo é condicional.
7. Lavanderia somente para períodos superiores a 7 dias.
8. Café R$15; almoço SP R$32/RJ R$35; jantar SP/RJ R$35.
9. Arquivos importados são validados antes de afetar relatórios.
