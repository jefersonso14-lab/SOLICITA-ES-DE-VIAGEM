# 08 — Solicitações de Viagem

Fluxo: Nova OS → Dados → Colaboradores → Serviços → Custos → Anexos → Revisão → Envio → Dossiê.

Status: rascunho, enviada, aprovada, em andamento, concluída e cancelada.

O dossiê concentra solicitação, participantes, serviços, custos, comprovantes, relatório e histórico.
