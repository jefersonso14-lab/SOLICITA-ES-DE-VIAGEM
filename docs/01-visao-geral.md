# 01 — Visão Geral

Centralizar solicitações de viagem, custos, comprovantes, relatórios e histórico em uma única plataforma.

Fluxo: Solicitação → Execução → Custos → Comprovantes → Consolidação → Relatório → Histórico.

Uma OS representa um dossiê digital completo. Solicitação e custo são entidades separadas e o histórico deve ser preservado.
